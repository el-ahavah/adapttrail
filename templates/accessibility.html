Use less data while planning

  • Leave the optional weather location blank to save an assessment without requesting a forecast.
  • Weather notices update only when you ask to check them. Previously saved forecasts can be out of date; check their retrieval time and status.
  • Low-data mode still needs an internet connection to load pages and save forms. It does not provide offline saving, SMS or USSD access.

Read a saved copy later

Open a saved assessment or project page, then use your browser's Print or Save as PDF option if available. The print layout keeps the page's text and removes navigation and input forms. Keep private copies secure, especially on shared devices. A saved forecast is a dated reference, not a live update.

Keyboard and screen access

Use Tab to move between controls and Enter to follow links. “Skip to content” goes straight to the page content. On narrow screens, open Menu to show navigation; Escape closes it. In low-data mode or without JavaScript, navigation stays visible. Weather tables can be focused and scrolled with arrow keys.

Browser zoom and larger text are supported by flexible layouts. Motion effects follow your device's reduced-motion setting. Screen-reader and real-device testing is still needed; this prototype does not claim full accessibility certification.
